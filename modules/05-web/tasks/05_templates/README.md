# 05. Страница каталога на html/template

Пакет `pages`. Урок: [Шаблоны и статические файлы](../../lessons/04-templates-static.md).

Не каждому сервису нужен SPA-фронтенд. Админку, страницу статуса или простой каталог проще отрендерить на сервере, и `html/template` здесь очень хорош: он сам экранирует данные с учётом контекста, в котором они выводятся. Мы сверстаем страницу каталога товаров с общим каркасом, пользовательской функцией для цен и защитой от XSS.

## Что сделать

```go
func NewRenderer() (*Renderer, error)
func (r *Renderer) Render(w io.Writer, p Page) error
func (r *Renderer) Handler(load func(*http.Request) (Page, error)) http.Handler
```

Типы `Item` и `Page` лежат в `types.go`. Шаблоны храните строковыми константами; в реальном проекте это были бы файлы, подключённые через `embed` и `template.ParseFS`. Каркас `layout` с `{{block "content" .}}` уже есть в заготовке.

`Render` выполняет шаблон `"layout"`, и вывод должен удовлетворять следующим требованиям:

- `<title>` содержит `Page.Title`;
- если `User` не пуст, выводится `<p class="greeting">Привет, {{.User}}!</p>`;
- непустой список выводится как `<ul>`, а каждый элемент — как `<li class="item"><a href="URL">Title</a> <span class="price">ЦЕНА</span> <span class="tags">теги</span></li>`, причём `span.tags` выводится только если теги есть (они склеиваются через `join` с разделителем `", "`);
- для пустого или nil списка выводится `<p class="empty">Пусто</p>` и никакого `<ul>` (здесь пригодится `{{with}}…{{else}}`);
- цену форматирует функция шаблона `price(cents int64) (string, error)`: из `1250` получается `"12.50 ₽"`, из `5` — `"0.05 ₽"`, а на отрицательную цену функция возвращает ошибку, и Execute прерывается;
- всё экранируется по контексту: `javascript:`-URL превращается в `#ZgotmplZ`, а теги — в `&lt;…&gt;`.

`Handler` при ошибке `load` или рендеринга отвечает 500, и в ответ не должны попасть обрывки HTML. Поэтому рендерить нужно сначала в `bytes.Buffer`. При успехе ответ — 200 с `Content-Type: text/html; charset=utf-8`.

## Подвохи

`text/template` не экранирует вообще ничего, и тест на XSS это сразу поймает.

`{{block}}` и переопределяющий его `{{define}}` нельзя разобрать одним вызовом `Parse`: получится ошибка multiple definition. Нужен второй вызов `t.Parse(content)`.

`Funcs` нужно вызвать до `Parse`, иначе получите «function not defined».

Разбирать шаблоны на каждый запрос медленно, да и незачем: `*template.Template` безопасен для параллельного `Execute`.
