# Задача 03. Конфиг из флагов и окружения: `flag.FlagSet` и свой `flag.Value`

Почти любому сервису нужны настройки, и приходят они обычно из двух мест: из флагов командной строки и из переменных окружения (так их удобно передавать в контейнер). Мы соберём небольшой парсер конфигурации, который объединяет оба источника с понятным приоритетом. Попутно разберёмся, как написать свой тип флага через интерфейс `flag.Value` и почему библиотечный код не должен сам печатать ошибки и завершать процесс.

Пакет `config`. Типы `Level`, `StringList` и `Config` объявлены в `types.go`, реализовать нужно в `config.go`:

```go
func (l Level) String() string          // "debug" | "info" | "warn" | "error" | "Level(N)"
func (l *Level) Set(s string) error     // без учёта регистра, "warning" == "warn"
func (s *StringList) String() string    // "a,b,c"
func (s *StringList) Set(v string) error // добавляет; "a, b" → два элемента; пустые пропускаются
func Parse(args []string, getenv func(string) string) (Config, error)
```

Поддерживаемые параметры:

| Флаг | Переменная | По умолчанию | Тип |
|---|---|---|---|
| `-addr` | `APP_ADDR` | `:8080` | string |
| `-timeout` | `APP_TIMEOUT` | `5s` | `time.Duration`, строго больше нуля |
| `-level` | `APP_LEVEL` | `info` | `Level` (свой `flag.Value`) |
| `-tag` (повторяемый) | — | пусто | `StringList` |
| `-v` | — | false | bool |
| позиционные | — | — | `Config.Files` |

Приоритет источников такой: значение по умолчанию перекрывается окружением, а окружение — флагами. Вызов выглядит так:

```go
cfg, err := config.Parse([]string{"-level=debug", "-tag", "a,b", "in.txt"}, os.Getenv)
```

## Требования

- Используйте `flag.NewFlagSet(name, flag.ContinueOnError)` и `SetOutput(io.Discard)`. Библиотечная функция ничего не печатает и не вызывает `os.Exit`: как реагировать на ошибку, решает `main`.
- На `-h` или `-help` возвращается ошибка, для которой `errors.Is(err, flag.ErrHelp)`.
- Ошибка в переменной окружения должна называть эту переменную (`APP_TIMEOUT: ...`), иначе пользователь не поймёт, что именно исправлять.

## Подвохи

Пакет `flag` прекращает разбор на первом позиционном аргументе. Поэтому `x.txt -v` — это два позиционных аргумента, и `-v` не установится. Разбор флагов завершает и `--`.

Запись `-timeout 5` — ошибка: `time.ParseDuration` требует единицы измерения.

В документации `flag.Value` сказано, что пакет может вызвать `String()` на нулевом получателе, например на nil-указателе. Значит, `(*StringList)(nil).String()` не должна паниковать.

Булев флаг задаётся только как `-v` или `-v=false`. Вариант `-v false` не работает так, как хочется: `false` превращается в позиционный аргумент.
