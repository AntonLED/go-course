# Задача 04. Подкоманды: `textkit`

У `git`, `go` и `docker` один и тот же интерфейс: сначала имя подкоманды, потом её собственные флаги. Напишем маленькую утилиту `textkit` в том же стиле. Помимо разбора подкоманд, задача учит дисциплине, которую ждут от любой CLI-утилиты: правильные коды возврата, справка и ошибки в stderr, чистый stdout, пригодный для пайпов.

Пакет `subcmd`. Константы (`ExitOK/ExitFailure/ExitUsage`, `Version`, `Usage`) лежат в `types.go`, реализовать нужно в `subcmd.go`:

```go
func Run(args []string, stdin io.Reader, stdout, stderr io.Writer) int
```

Функция `main` утилиты состоит из одной строки: `os.Exit(subcmd.Run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))`. Благодаря этому всё поведение можно протестировать, не запуская отдельный процесс.

```
textkit [-json] <command> [flags] [args]
```

| Команда | Флаги | Поведение | `-json` |
|---|---|---|---|
| `count` | `-lines -words -bytes` (без флагов — все три) | статистика по stdin: `lines=2 words=3 bytes=25` (порядок всегда lines, words, bytes; lines — число `\n`) | `{"lines":2,"words":3}` — только выбранные |
| `repeat` | `-n N` (2), `-sep S` (`" "`) | `TEXT` = аргументы через пробел; печатает TEXT N раз через S и `\n` | `["x","x"]`; при `-n 0` — `[]` |
| `upper` | — | stdin → stdout в верхнем регистре, потоково | игнорируется |
| `version` | — | `textkit 1.2.0` | `{"version":"1.2.0"}` |

В колонке флагов в скобках указаны значения по умолчанию: у `-n` это 2, у `-sep` — пробел.

## Коды возврата и потоки

- `0` — успех. Тот же код возвращают `-h` и `-help`, как глобальные, так и у команды; справка при этом печатается в stderr.
- `2` — ошибка использования: нет команды, неизвестная команда, неизвестный или некорректный флаг, лишние или недостающие аргументы, `-n < 0`. В stderr выводится сообщение (и/или справка), а stdout остаётся пустым.
- `1` — ошибка выполнения, например упало чтение stdin. Причина пишется в stderr.

## Подвохи

У каждой подкоманды свой `flag.FlagSet` с `ContinueOnError`, а глобальные флаги разбираются до имени команды. Поэтому `textkit count -json` — ошибка: команда `count` флага `-json` не знает.

`flag.ErrHelp` для пользователя не ошибка, и код возврата в этом случае 0.

`upper` пишет через `bufio.Writer`, так что не забудьте `Flush`, иначе хвост вывода потеряется. Большой ввод при этом не должен читаться в память целиком.

И последнее: `json.Marshal` для nil-среза даёт `null`, а не `[]`.
