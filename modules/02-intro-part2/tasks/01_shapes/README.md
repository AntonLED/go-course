# Задача 01. Фигуры: интерфейсы, Stringer, sort.Interface, type switch

Пакет `shapes`. Геометрические фигуры — учебный пример, которым интерфейсы объясняют во всех языках, но в Go у него есть своя изюминка: одни методы объявлены на значении, другие на указателе, и от этого зависит, какие интерфейсы тип реализует. Именно это задача и проверяет.

Типы `Shape`, `Scaler`, `Circle`, `Rect`, `Triangle` и `ByArea` уже объявлены в `types.go`, а методы и функции нужно реализовать в `shapes.go`.

## Что сделать

1. Методы `Area()`, `Perimeter()` и `String()` для `Circle`, `Rect` и `Triangle`, с получателем-значением.
   - Строковое представление: `Circle{R: 1.5}.String()` даёт `"Circle(r=1.5)"`, `Rect{2,3}` — `"Rect(2x3)"`, `Triangle{3,4,5}` — `"Triangle(3, 4, 5)"`. Числа форматируются через `%g`.
   - Площадь треугольника считается по формуле Герона. Для невозможного или вырожденного треугольника, а также если какая-то сторона неположительна, площадь равна `0`. Периметр же всегда просто сумма сторон, даже для невалидного треугольника.
2. Метод `Scale(k float64)` для `*Circle` и `*Rect`, с получателем-указателем.
3. Реализация `sort.Interface` для `ByArea`: сортировка по возрастанию площади.
4. Функции:

```go
func TotalArea(shapes ...Shape) float64          // nil-элементы пропускаются
func Largest(shapes []Shape) (Shape, bool)       // при равенстве — первая
func ScaleAll(shapes []Shape, k float64) int     // масштабирует только Scaler'ы
func Describe(s Shape) string                    // type switch, см. комментарий в shapes.go
```

## Подвохи

`Circle` как значение не реализует `Scaler`: в method set значения нет методов с получателем-указателем. Поэтому для `[]Shape{&Circle{}, Circle{}, &Rect{}, Triangle{}}` функция `ScaleAll` должна вернуть `2`.

С `Describe((*Rect)(nil))` другая ловушка. Такой интерфейс не равен `nil` — в нём лежит тип `*Rect`, — но указатель внутри нулевой, и разыменовывать его нельзя.

Обратите внимание и на type switch: в ветке `case Circle, *Circle:` переменная из `switch v := s.(type)` имеет тип интерфейса, а не один из конкретных типов.

Наконец, вызов метода на `nil`-интерфейсе приводит к панике, поэтому `TotalArea` сначала проверяет `s == nil`.
