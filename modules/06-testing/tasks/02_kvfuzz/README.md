# 02. Формат key=value: golden-файлы и фаззинг

Пакет `kv`. Урок: [Тестирование в Go](../../lessons/01-testing.md).

Строки вида `level=info msg="user created" id=42` вы наверняка видели в логах: это logfmt, простой и удобный для grep формат. Мы напишем сериализатор похожего формата. Сам по себе он несложен, но именно в таком коде прячутся баги на экранировании, пустых значениях и странных байтах, и найти их руками почти невозможно. Поэтому тесты этой задачи показывают сразу несколько техник из урока: табличные тесты, black-box пакет `kv_test`, golden-файл в `testdata/` с флагом `-update`, `Example`-функцию с `// Output:`, детерминированный рандомизированный тест и два фаззера.

## Что сделать

```go
func Encode(m map[string]string) (string, error)
func Decode(s string) (map[string]string, error)
```

Ошибки — сентинелы из `errors.go`: `ErrInvalidKey`, `ErrSyntax` и `ErrDuplicateKey`. Возвращайте их обёрнутыми через `%w`.

### Формат

Пары `ключ=значение` разделяются ровно одним пробелом, ключи идут по возрастанию (`slices.Sort`). Пустая карта кодируется в `""`.

Ключ должен быть непустым и состоять только из символов `[A-Za-z0-9_.-]`, иначе возвращается `ErrInvalidKey`.

Значение пишется как есть («bare»), если оно непустое и все его байты лежат в диапазоне `0x21..0x7E`, за исключением `"`, `=` и `\`. Иначе значение берётся в кавычки через `strconv.Quote`, который экранирует кавычки, `\`, управляющие символы и невалидный UTF-8 (в виде `\xff`).

```
{"user":"ann", "msg":"hello world", "n":"5"}  →  msg="hello world" n=5 user=ann
{"a":""}                                       →  a=""
```

### Decode

- Пары разделяются одним или несколькими пробелами `' '`, пробелы по краям строки допустимы. Строка `""` декодируется в пустую карту, не `nil`.
- Если в паре нет `=`, возвращается `ErrSyntax`; если ключ невалиден или пуст — `ErrInvalidKey`.
- Для значения в кавычках нужно найти закрывающую кавычку с учётом `\`-экранирования и раскодировать значение через `strconv.Unquote`. После закрывающей кавычки допустим только пробел или конец строки. Незакрытая кавычка или плохой escape дают `ErrSyntax`.
- Bare-значение продолжается до пробела. Пустое значение (`a=`) или значение с недопустимым байтом (`"`, `=`, `\`, таб, не-ASCII) даёт `ErrSyntax`.
- Повтор ключа даёт `ErrDuplicateKey`.

Главное свойство, которое проверяют фаззеры, звучит так: для любой карты с валидными ключами `Decode(Encode(m)) == m`, а любая строка, которую `Decode` принял, переживает кодирование и повторное декодирование без изменений.

## Запуск проверки

```
go test -race ./modules/06-testing/tasks/02_kvfuzz/
go test -run TestEncodeGolden ./modules/06-testing/tasks/02_kvfuzz/ -args -update   # перегенерировать golden
go test -run XXX -fuzz=FuzzDecode -fuzztime=30s ./modules/06-testing/tasks/02_kvfuzz/   # фаззинг
```

Если фаззер найдёт падение, он сохранит вход в `testdata/fuzz/FuzzDecode/…`, и с этого момента этот вход станет обычным регрессионным тестом.
