# 03. Фейковые часы, TTL-кэш и Poll

Пакет `clock`. Урок: [Мокирование и тестирование API](../../lessons/02-mocking.md).

Код, который напрямую вызывает `time.Now()` и `time.Sleep()`, тестировать больно. Тест на «запись протухает через час» будет идти час, а тест на «опрос раз в минуту» начнёт флакать. Выход — сделать код зависимым от интерфейса `Clock` (он объявлен в `clock.go`) и подставлять в тестах управляемый фейк, у которого время идёт только тогда, когда тест этого хочет.

## Что сделать

```go
// Фейк
func NewFake(start time.Time) *Fake
func (f *Fake) Now() time.Time
func (f *Fake) After(d time.Duration) <-chan time.Time
func (f *Fake) Advance(d time.Duration)
func (f *Fake) Waiters() int
func (f *Fake) BlockUntil(n int)

// Код, использующий Clock
func NewTTLCache[K comparable, V any](c Clock, ttl time.Duration) *TTLCache[K, V]
func (c *TTLCache[K, V]) Set(k K, v V)
func (c *TTLCache[K, V]) Get(k K) (V, bool)
func (c *TTLCache[K, V]) Len() int
func Poll(ctx context.Context, c Clock, interval time.Duration, cond func() (bool, error)) error
```

### Fake

Фейк должен быть потокобезопасным: тест и тестируемые горутины обращаются к нему одновременно.

`After(d)` возвращает канал с буфером 1. Если `d <= 0`, значение `Now()` кладётся в канал сразу, иначе таймер ждёт, пока время дойдёт до дедлайна.

`Advance(d)` сдвигает время и срабатывает все таймеры, у которых дедлайн `<=` нового времени. Таймеры срабатывают по возрастанию дедлайна, каждый ровно один раз, и в канал отправляется момент срабатывания, то есть дедлайн. `Advance` никогда не блокируется, даже если канал никто не читает.

`Waiters()` возвращает число несработавших таймеров, а `BlockUntil(n)` ждёт (через `sync.Cond`), пока их станет не меньше `n`. Это главный инструмент синхронизации: тест дожидается, пока горутина «уснёт» на `After`, и только потом двигает время. Без него получится гонка, в которой `Advance` случается раньше `After`.

### TTLCache

Запись, положенная в момент $t$, видна, пока `Now()` меньше $t + \mathit{ttl}$, и протухает ровно в момент $t + \mathit{ttl}$. Протухшие записи удаляются при `Get` и `Len`. Повторный `Set` того же ключа продлевает жизнь записи. Кэш должен быть потокобезопасным.

### Poll

`Poll` сразу вызывает `cond`. Если та вернула `true`, `Poll` возвращает `nil`; если ошибку — возвращает её. В остальных случаях `Poll` ждёт либо `c.After(interval)`, либо `ctx.Done()` (и тогда возвращает `ctx.Err()`), после чего повторяет всё сначала.

## Подвохи

Если внутри `Poll` написать `time.After` вместо `c.After`, тест с фейком зависнет: `time.After` ждёт настоящее время, а тест двигает только фейковое.

Небуферизованный канал в `After` в сочетании с `Advance`, отправляющим под мьютексом, даёт дедлок.

Сравнивать время через `==` нельзя, используйте `Equal` и `Before`: мешают монотонные часы и часовые пояса.
