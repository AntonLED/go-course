# 05. Анаграммы, инверсия map, Two Sum

Задача к уроку [«Работа с картами (map)»](../../lessons/05-maps.md). Все три функции решаются через `map`, и все три проверяют одну и ту же привычку: не полагаться на порядок обхода карты. Результат должен быть одинаковым при каждом запуске, хотя сам runtime этого не гарантирует.

## Что сделать

```go
func GroupAnagrams(words []string) [][]string
func Invert(m map[string]int) map[int][]string
func TwoSum(nums []int, target int) (i, j int, ok bool)
```

`GroupAnagrams` группирует слова-анаграммы. Регистр не учитывается, сравнение идёт по рунам, так что кириллица тоже должна работать. Результат детерминирован: группы идут в порядке первого появления, слова внутри группы — в порядке входа, дубликаты сохраняются.

```go
GroupAnagrams([]string{"eat", "tea", "tan", "ate", "nat", "bat"})
// [[eat tea ate] [tan nat] [bat]]
```

`Invert` переворачивает карту: из `{"a":1, "b":2, "c":1}` получается `{1: ["a","c"], 2: ["b"]}`. Списки ключей отсортированы. `Invert(nil)` возвращает пустую, но не `nil` карту.

`TwoSum` ищет индексы `i < j`, для которых `nums[i] + nums[j] == target`, за один проход по срезу. Если подходящих пар несколько, выбирается пара с минимальным `j`, а при нём — с минимальным `i`.

## Подвохи

Порядок обхода `map` случаен: runtime специально рандомизирует стартовый бакет, чтобы никто на него не полагался. Поэтому строить результат простым обходом карты нельзя, а тест на всякий случай прогоняет функцию 20 раз.

Запись в `nil`-карту вызывает панику, чтение — нет. Отличить «ключа нет» от нулевого значения можно только через `v, ok := m[k]`, и в `TwoSum` это особенно важно: индекс `0` — вполне законный ответ.

Там же не перезаписывайте сохранённый индекс, если значение повторяется, иначе потеряете минимальный `i`.
