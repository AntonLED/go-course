# Задание 1. Мини-библиотека

Итоговая задача модуля «Введение в Go. Часть 1». Вы напишете маленький каталог библиотеки: книги можно добавлять, выдавать читателям, искать и выводить отчётом. Звучит буднично, но в этой задаче сходится всё, что было в уроках: структуры и методы с получателем-указателем, `map` с её неадресуемыми элементами и случайным порядком обхода, срезы и aliasing, строки с Unicode, сортировка и форматированный вывод.

## Что сделать

Ошибки-сентинелы и типы `Book`, `AuthorStat`, `TagCount` уже объявлены в `types.go`. В `library.go` реализуйте тип `Library` и его методы:

```go
func New() *Library
func (l *Library) Add(b Book) error
func (l *Library) Get(isbn string) (Book, bool)
func (l *Library) Checkout(isbn, reader string) error
func (l *Library) Return(isbn string) error
func (l *Library) Search(query string) []Book
func (l *Library) AuthorStats() []AuthorStat
func (l *Library) TopTags(n int) []TagCount
func (l *Library) Report() string
```

### Правила

**Add.** Прежде чем сохранить книгу, её нужно привести в порядок:

- ISBN нормализуется: из него убираются `-` и пробелы. После этого должна остаться непустая строка из цифр, причём последний символ может быть `X` или `x` (хранится как `X`). Если это не так, возвращается `ErrInvalidBook`.
- `Title` и `Author` обрезаются через `strings.TrimSpace` и должны остаться непустыми, иначе тоже `ErrInvalidBook`.
- Теги проходят через `TrimSpace` и `ToLower`, пустые выбрасываются, повторы убираются, порядок первых вхождений сохраняется.
- Если книга с таким ISBN (после нормализации) уже есть, возвращается `ErrDuplicate`.
- Библиотека не должна разделять память со срезом `b.Tags` вызывающего.

**Get** принимает ISBN в любом виде, например `"978-5-..."`, и возвращает глубокую копию книги.

**Checkout и Return** возвращают `ErrInvalidReader`, если читатель пустой, `ErrNotFound`, если книги нет, `ErrCheckedOut`, если книга уже выдана, и `ErrNotCheckedOut`, если возвращают книгу, которую не выдавали. Ошибки можно оборачивать через `%w`.

**Search** ищет подстроку в `Title` или `Author` без учёта регистра, и кириллица тоже должна работать: `"ТОЛСТОЙ"` находит «Лев Толстой». Пустой запрос возвращает все книги. Результат упорядочен по `strings.ToLower(Title)`, а при равенстве — по `ISBN`. Строки сравниваются побайтово, поэтому латиница окажется раньше кириллицы. Возвращаются копии книг.

**AuthorStats** сортирует авторов по убыванию числа книг, а при равенстве — по имени автора.

**TopTags(n)** сортирует теги по убыванию частоты, а при равенстве — по самому тегу. При `n <= 0` результат пустой.

**Report** строит таблицу. Ниже показаны первые строки отчёта для набора книг из тестов. Ширина колонок считается по всем книгам, поэтому колонка Author шире, чем требуется для трёх показанных строк:

```
ISBN          | Title                       | Author            | Year | Status
--------------+-----------------------------+-------------------+------+-----------
111           | go in action                | William Kennedy   | 2015 | available
030640615X    | The Go Programming Language | Alan Donovan      | 2015 | out: Мария
9785389074354 | Анна Каренина               | Лев Толстой       | 1877 | available
```

Формат отчёта:

- колонки `ISBN, Title, Author, Year, Status`; `Status` — это `available` или `out: <читатель>`;
- ширина колонки — максимум в рунах по заголовку и всем значениям, выравнивание влево, разделитель `" | "`;
- вторая строка состоит из дефисов по ширине колонок, соединённых через `"-+-"`;
- пробелы в конце каждой строки обрезаются, и каждая строка заканчивается `\n`;
- строки идут в том же порядке, что у `Search("")`.

## Подвохи

Элемент `map` неадресуем: если значение — структура, `l.books[isbn].reader = "x"` просто не скомпилируется. Храните в карте `*entry` или действуйте по схеме «прочитал, изменил, записал обратно».

Вторая ловушка — aliasing. `Book` копируется по значению, но `Tags` — срез, и копия структуры смотрит на тот же массив, что и оригинал. Тесты это проверяют: они меняют и исходный срез, и то, что вернули `Get` и `Search`.

Порядок обхода `map` случаен, так что любой вывод нужно сортировать. Для составного ключа удобна связка `slices.SortFunc` и `cmp.Or`.

Ширину считайте в рунах: `len("Толстой") == 14`. Хорошая новость в том, что `fmt` с `%-*s` отсчитывает ширину именно в рунах. А чтобы последняя колонка не оставляла пробелов в конце строки, пригодится `strings.TrimRight(line, " ")`.
