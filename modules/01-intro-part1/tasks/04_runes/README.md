# 04. Строки, руны и UTF-8

Задача к уроку [«Работа со строками»](../../lessons/04-strings.md). Четыре функции, которые на латинице пишутся за минуту, а на кириллице ломаются, если думать о строке как о массиве символов. В Go строка — это последовательность байтов в UTF-8, и все четыре задачи проверяют, помните ли вы об этом.

## Что сделать

```go
func Reverse(s string) string
func IsPalindrome(s string) bool
func Compress(s string) string
func Caesar(s string, shift int) string
```

| Функция | Требования | Пример |
|---|---|---|
| `Reverse` | Разворачивает строку по рунам. Битые байты превращаются в `U+FFFD`. | `"Привет"` → `"тевирП"` |
| `IsPalindrome` | Учитывает только буквы и цифры (`unicode.IsLetter/IsDigit`), регистр не важен. Пустая строка — палиндром. | `"А роза упала на лапу Азора"` → `true` |
| `Compress` | RLE по рунам: серия из `n > 1` одинаковых рун записывается как руна и число `n`, одиночная руна остаётся как есть. | `"aaabcc"` → `"a3bc2"`, `"ёёж"` → `"ё2ж"` |
| `Caesar` | Сдвигает латинские буквы `a–z` и `A–Z` по кругу с сохранением регистра, всё остальное оставляет без изменений. `shift` может быть любого знака и любой величины. | `Caesar("xyz", 3)` → `"abc"` |

## Подвохи

`s[i]` — это байт, и `len(s)` тоже считает байты. Поэтому разворот через `[]byte` ломает кириллицу: двухбайтовые символы разваливаются на части. Цикл `for i, r := range s` идёт по рунам, но `i` в нём — байтовый индекс начала руны, а не порядковый номер символа.

Не склеивайте результат через `+=` в цикле: каждая конкатенация копирует строку целиком, и по памяти выходит $O(n^2)$. Для этого есть `strings.Builder`.

В шифре Цезаря помните, что в Go `-1 % 26 == -1`, так что сдвиг нужно нормализовать. А в палиндроме — что `"Ё"` и `"ё"` это разные руны: сравнивайте их после `unicode.ToLower`.
