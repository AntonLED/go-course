# 01. FizzBuzz и таблица

Это разминка к уроку [«Осознанное знакомство с Go»](../../lessons/01-meet-go.md). Сама задача простая, и так задумано: смысл в том, чтобы один раз пройти весь цикл работы с toolchain целиком — написать код, отформатировать его `gofmt`, проверить `go vet` и прогнать тесты через `go test`. Попутно вы наткнётесь на первую ловушку Go со строками: длина в байтах и ширина в символах — не одно и то же.

## Что сделать

В файле `fizzbuzz.go` реализуйте две функции:

```go
func FizzBuzz(n int) []string
func Columns(items []string, cols int) string
```

`FizzBuzz` — та самая классика с собеседований. Для каждого числа от 1 до `n` включительно в результат попадает `"FizzBuzz"`, если число кратно 15, `"Fizz"`, если кратно 3, `"Buzz"`, если кратно 5, а в остальных случаях само число строкой. При `n <= 0` функция возвращает пустой, но не `nil` срез (`[]string{}`).

`Columns` раскладывает элементы в таблицу по `cols` штук в строке — так выглядел бы вывод FizzBuzz, если бы его печатали аккуратными колонками. Правила такие:

- каждая ячейка выровнена вправо по ширине самого длинного элемента;
- ширина считается в символах (рунах), а не в байтах: у `"кот"` ширина 3, хотя `len("кот") == 6`;
- ячейки разделяются одним пробелом, каждая строка, включая последнюю неполную, заканчивается `\n`, а недостающие ячейки последней строки пробелами не дополняются;
- если `cols <= 0` или `items` пуст, результат — пустая строка `""`.

```go
Columns([]string{"1", "2", "Fizz", "4"}, 2)
// "   1    2\n"
// "Fizz    4\n"
```

## Подсказки

Для перевода числа в строку хватит `strconv.Itoa`, а цепочку проверок удобно записать через `switch` без выражения: `switch { case i%15 == 0: ... }`.

Выравнивание вправо умеет делать `fmt`: в `fmt.Fprintf(&b, "%*s", width, s)` ширина берётся из аргумента, и `fmt` отсчитывает её в рунах. Саму максимальную ширину найдёте с помощью `utf8.RuneCountInString` и встроенной `max` (она появилась в Go 1.21), а результат удобно собирать в `strings.Builder`.

## Подвохи

Следите за порядком проверок: если первой стоит проверка на `%3`, то 15 превратится в `"Fizz"`. Помните, что `len(s)` для кириллицы возвращает байты, а не символы. И не путайте `nil` с пустым срезом — тест различает эти случаи.
