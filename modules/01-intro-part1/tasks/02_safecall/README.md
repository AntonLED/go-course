# 02. SafeCall, Counter, Compose

Задача к уроку [«Основы синтаксиса»](../../lessons/02-syntax.md). Три небольшие функции, и каждая упирается в свою особенность языка: `defer`/`panic`/`recover`, именованные результаты, замыкания и variadic-функции. `SafeCall` — упрощённая версия того, что делает любой HTTP-сервер или воркер, который не должен падать целиком из-за паники в одном обработчике.

## Что сделать

Тип `PanicError` и ошибка `ErrNilFunc` уже объявлены в `types.go`. В `safecall.go` реализуйте:

```go
func SafeCall(f func()) (err error)
func Counter(start, step int) (next func() int, reset func())
func Compose(fs ...func(int) int) func(int) int
```

`SafeCall` вызывает `f` и превращает панику в ошибку:

- если `f == nil`, возвращается `ErrNilFunc`;
- если `f` отработала без паники, возвращается `nil`;
- если `f` запаниковала со значением `v`, возвращается `&PanicError{Value: v}`. У `PanicError` есть `Unwrap`, поэтому, если паниковали ошибкой, сработает `errors.Is(err, io.EOF)`.

`Counter` возвращает два замыкания над общим состоянием. `next()` выдаёт по очереди `start`, `start+step` и так далее, а `reset()` возвращает счётчик в начало. Разные счётчики друг от друга не зависят.

`Compose` строит композицию функций слева направо: `Compose(inc, dbl)(3) == 8`, то есть сначала `inc`, потом `dbl`. Вызванная без аргументов, она возвращает тождественную функцию.

## Подвохи

`recover()` останавливает панику только внутри отложенной функции, причём вызванной напрямую, а не из вложенного вызова. Вернуть ошибку из `defer` можно лишь через именованный результат — поэтому в сигнатуре `SafeCall` он уже есть.

Начиная с Go 1.21, `panic(nil)` не «проглатывается» тихо: `recover()` вернёт `*runtime.PanicNilError`, так что и в этом случае `SafeCall` должна вернуть ошибку.

И последнее. Variadic-параметр — это обычный срез, и при вызове `Compose(list...)` он разделяет память со срезом `list`. Изменение `list[0]` после вызова `Compose` не должно менять поведение уже построенной композиции, так что подумайте, что именно вы захватываете в замыкание.
